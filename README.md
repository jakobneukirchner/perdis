# Perdis Android App

Android-Anwendung zum Auslesen von Perdis-Schichten und Dienstplänen.

## Features

- Unsichtbarer WebView-Login
- Schichten-Übersicht (shift.aspx)
- Perlschnur-Layout für Fahrtinformation
- Verschlüsselte Credential-Speicherung
- Material Design 3

## Installation

1. Repository klonen
2. Android Studio öffnen
3. Gradle Sync
4. Run

## URLs

- Login: `https://perdisweb.verkehrs-ag.de/WebComm/default.aspx`
- Schichten: `https://perdisweb.verkehrs-ag.de/WebComm/shift.aspx?YYYY-MM-DD`
- Roster: `https://perdisweb.verkehrs-ag.de/WebComm/roster.aspx?YYYY-MM-DD`
- PDF: `https://perdisweb.verkehrs-ag.de/WebComm/shiprint.aspx?YYYY-MM-DD`
